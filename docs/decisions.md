# Decisions and constraints

- **Versions:** Next 16.3.5, React 19.3.0, Prisma 7.10.0 and Better Auth 1.7.5 were checked against npm/current official docs. Prisma's `latest` tag pointed to an 8.0 release candidate, so stable 7.10.0 was selected. Actual transitive versions are in the lockfile. Read installed Next documentation and AGENTS.md before framework changes.
- **Whole sale units:** Inventory supports boxes/pieces/sets/packs and integer increments. Fractional surface area is a calculator/display quantity, not fractional stock. This avoids floating-point inventory errors. Extend with a scaled integer quantity if fractional bulk sales are validated later. Listing total value is capped at ৳20,000,000 to fit the current integer monetary schema safely.
- **Search:** NFKC normalization, lowercase and whitespace normalization; parameterized PostgreSQL ILIKE substring matching plus `pg_trgm` similarity/word similarity. Exact codes and Bangla strings work without assuming English stemming applies to Bangla. The threshold is heuristic, not a trained matching system. Filters include category, area, price, minimum available quantity, dimensions, brand/model, finish, condition and partial lots. Indexes cover public/category/area, seller state, price and trigram text.
- **Location:** Approximate district/area only. No coordinates are invented and no permission prompt is shown. Radius/distance search is not implemented.
- **One listing = one batch:** Different shades/lots require separate listings. Unknown optional details remain null. Required dimensions for tiles/doors/flooring are seller-declared, not inferred from pictures or claimed independently inspected.
- **State machines:** Order: PENDING → ACCEPTED → READY → COMPLETED; PENDING → DECLINED; eligible PENDING/ACCEPTED/READY → CANCELLED; overdue held ACCEPTED/READY → EXPIRED. Cancellation stops after either handover confirmation. Reservation: HELD → CONSUMED / RELEASED / EXPIRED. Payment: UNCONFIRMED → SELLER_CONFIRMED independently. Dispute: OPEN → RESOLVED with reason only. Promotion: verified payment → seven-day active placement; confirmed simulated refund/expiry deactivates.
- **Promotion scope:** Platform-owned advertising only. No buyer material-fund collection or payouts. Sandbox initiation/validation adapter exists, but live provider credentials/acceptance are not proven. Refund simulation is local-only; live refund support is not implemented.
- **UI:** Custom accessible native HTML controls plus Lucide icons, Tailwind v4 and focused CSS. No decorative ratings, urgency or fake impact figures. English/Bangla user-facing core copy, form validation and transactional emails; remaining English operational/matching labels need translation review before launch.
- **Local services:** Docker Compose specifies PostgreSQL, MinIO and Mailpit. This machine lacks Docker, so execution used real embedded PostgreSQL 18.4, S3rver and a loopback SMTP receiver. Those are development conveniences, not production adapters.
- **No distance/courier claims:** Pickup and buyer-arranged transport only. No invented delivery tracking, fixed haulage prices or material safety certifications.
- **Testing scope:** Database transaction tests are real PostgreSQL. Provider fixtures are contract tests only. Browser tests use real Chrome and a seeded local stack. Scores are observations under the stated local profile, not certifications.
